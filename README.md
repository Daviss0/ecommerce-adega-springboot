\# Adega do Campinho



Sistema de e-commerce para adega desenvolvido com Spring Boot, com foco em gerenciamento de produtos, estoque, clientes e vendas online.



\## Objetivo do Projeto



O projeto tem como objetivo desenvolver uma plataforma de e-commerce onde:



\- Administradores possam gerenciar produtos, estoque e clientes.

\- Clientes possam acessar a loja virtual, visualizar produtos e realizar pedidos.



O sistema está sendo desenvolvido utilizando arquitetura MVC com Spring Boot.

\## Funcionalidades Implementadas



\### Painel Administrativo (Backoffice)

\- Upload de imagens

\- Controle de estoque

\- Visualização de produtos em modal

\- Cadastro de clientes

\- Controle de usuários

\- Login administrativo

\- Controle de permissões



\### Área do Cliente (Frontoffice)



\- Login de cliente

\- Cadastro de cliente

\- Carrinho de compras

\- Cálculo de frete via CEP

\- Controle de quantidade de produtos

\- Visualização de produtos
